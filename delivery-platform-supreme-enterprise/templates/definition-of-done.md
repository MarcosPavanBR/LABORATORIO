# Definition of Done

Uma tarefa está DONE quando: código e docs correspondem; testes realmente executados; status do CI conhecido; mudanças sensíveis revisadas por outro executor/humano se disponível; migrations e rollback verificados; alteração de custos e impactos comunicados; evidências sem segredo; caso de falha contemplado; lacunas e aceitação humanas declaradas; usuário tem comando reproduzível. `feature shipped` exige implantação real autorizada e telemetria, não merge.
